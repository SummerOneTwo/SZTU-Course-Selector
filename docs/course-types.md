# 教务系统选课类型说明

## 选课阶段

| 阶段 | 时间 | 方式 | 说明 |
|------|------|------|------|
| 第一轮初选 | 1月16日-19日 / 1月20日-22日 | 抽签 | 系统随机抽签，与选课时间无关 |
| 第二轮确认 | 3月2日-5日 | 抢选 | 先到先得，热门课程增加名额 |
| 重修选课 | 3月6日-9日 | 抢选 | 重修原课程或替代课程 |
| 第三轮补选 | 3月10日-15日 | 抢选 | 先到先得，满员为止 |

**注意**：每日选课时间为 09:00-22:00

## 课程类型

| 类型 | 说明 | cno 参数 |
|------|------|----------|
| 本学期计划选课 | 培养方案要求的必修课程 | "0" |
| 专业内跨年级选课 | 本专业其他年级开设的课程 | "1" |
| 跨专业选课 | 非本专业开设的课程 | "1" |
| 公选课选课 | 公共选修课程 | "0" |

## 选课规则

### 主选与非主选

- 课表安排的行政班学生是**主选身份**
- 其他学生是**非主选身份**
- 初选阶段：按身份分开抽签，优先级：行政班 → 计划内 → 培养方案内 → 方案外
- 确认/补选阶段：按身份分开抢选，留意剩余容量
- 补选阶段：不区分身份，按容量先到先得

### 学位释放

抢选阶段，课程满员后，有学生退课时**不立即释放学位**，系统在随机时间进行释放。

### 注意事项

- 相同课程号的课程不能重复选课
- 已修读并取得学分的课程不能重复选课
- 部分课程存在专业方向，跨方向课程允许选课
- 免听免修申请时间：3月2日-8日（申请期间该课程不可选）
